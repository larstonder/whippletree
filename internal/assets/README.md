# Brand source

`logo.svg` is the editable master: the full artwork on its original canvas, with
the fillet/chamfer path effects still live. Flatten those and the rounded corners
stop being adjustable, so edit this file rather than an export.

Everything the site serves is exported from here and committed under
`site/brand/`. Those exports are the artifacts; this is the source. Nothing else
belongs in this directory, because a second copy of an export is a copy that
drifts.
